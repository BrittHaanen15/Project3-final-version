# Studying a Penning trap system using 4-th order Range-Kutta methods

This repository contains the code for Project 3 in the course FYS3150/FYS4150 at the University of Oslo. 
The project is developed by: Britt Haanen

In this project we studied the motion of particles in a Penning Trap, comparing Forward Euler and Runge-Kutta methods for evolving the system through time. We examined the motion of particles against analytical solutions and briefly looked into resonance phenomena.
The computations are implemented in C++, while Python scripts are used for visualizing the results. 


## Repository structure

The repository is organised using the src/include convention, and the file tree is as follows: 
```text
├── Benchmarking
│   ├── Euler, after 1 step, as benchmark for RK4, compare against handwritten.png
│   ├── UnitTest_FEstep.cpp
│   ├── UnitTest_ParticleClass.cpp
│   ├── ...
├── Figures
│   ├── Error vs n, FE.pdf
│   ├── Error vs n, RK4.pdf
│   ├── ...
├── Plotting
│   ├── Plotting_100_particle.ipynb
│   └── Plotting_one_and_two_particle.ipynb
├── Project3_Outputs
│   ├── 100_particles_f0.1.csv
│   ├── 100_particles_f0.4.csv
│   ├── 100_particles_f0.7.csv
│   ├── ...
├── include
│   ├── Particle.hpp
│   ├── PenningTrap.hpp
│   └── utils.hpp
└── src
|   ├── Particle.cpp
|   ├── PenningTrap.cpp
|   └── utils.cpp
├── 100_particle_system.cpp
├── Two_particle_system.cpp
├── README.md
```

- `Benchmarking` contains unit test files for some of the functions and classes in 'src/'. It also contains screenshots of some of the printed outputs that were compared against hand calculations
- `Figures/` contains the figures generated by the python script
- `Plotting/` contains the Python scripts for plotting
- `Project3_Outputs/` contains the output data generated by the C++ scripts 
- `include/` contains header files
- `src/` contains source files 
- The two .cpp files in the main folder are the ones used for generating the results



## Requirements 
The C++ code requires a compiler supporting C++20. 

The Python scripts require Python 3 and the packages pandas, NumPy and Matplotlib.


## Building and running the code 
To build a code run the command

```
g++ -Wall FILE_TO_BUILD.cpp src/*.cpp -I include -o FILE_TO_BUILD.exe
```

To run the program, do

```
./FILE_TO_BUILD.EXE 
```

Figures from the report can be generated by providing the inputs to the simulation as indicated in Appendix B

The generated data is printed to terminal or stored in the `Project2_outputs/` directory. 

## Plotting
Generate the interactively by opening the `Plotting.ipynb` Jupyter notebook in the `plotting/` folder and running the code cells.

The corresponding files are automatically stored in the `plotting/` directory.
